# Forma: In-Game World Editor

**Forma** turns Minecraft 1.12.2 into a visual world editor. Press **Right Shift** to leave your player behind, then fly a free camera and edit the world with panels and tools instead of commands.

![Editor overview](https://raw.githubusercontent.com/kristitrnka/FromaMod/main/docs/images/editor-overview.webp)

---

## ✨ Features

- **Free-fly editor camera** with dockable panels
- **Selections:** Box Select and Magic Select, with fill, delete, copy, cut, rotate, flip and replace
- **3D move gizmo:** drag the arrows or nudge with the arrow keys
- **Build tools:** Pencil, Eraser, Bucket Fill, Shapes (sphere, cube or cylinder), Path, Text, Extrude, Paste and Ruler
- **Terrain brushes:** Sculpt, Smooth, Flatten, Noise, Paint, Scatter and Melt/Grow
- **Tool masks:** limit edits by block, height, selection, nearby blocks and more
- **Undo / Redo:** up to 50 steps, each with a block count
- **Schematics:** save and load `.schematic` and `.schem` files

---

## 🏔️ Terrain Brushes

Shape hills, valleys and coastlines. Each brush has an adjustable radius and strength.

![Terrain brushes](https://raw.githubusercontent.com/kristitrnka/FromaMod/main/docs/images/terrain-brushes.webp)

## 📦 Selection & Editing

Select a region, then fill, replace, copy, rotate or flip it with one click.

![Selection tools](https://raw.githubusercontent.com/kristitrnka/FromaMod/main/docs/images/selection-tools.webp)

## 🧭 Move Whole Builds

Pick up a house and move it with the gizmo. Press **Enter** to apply or **Esc** to cancel.

![Moving a selection](https://raw.githubusercontent.com/kristitrnka/FromaMod/main/docs/images/move-selection.webp)

---

## 🎮 Controls

| Input | Action |
|---|---|
| **Right Shift** | Open / close the editor |
| WASD, Jump, Sneak | Fly |
| Left mouse drag | Rotate camera |
| Right mouse | Use the current tool |
| Middle mouse | Pick block |
| Scroll | Change fly speed |
| 1–9 | Switch tool |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+C / X / V | Copy / cut / paste |
| F / Delete | Fill / delete selection |
| R / X / Z | Rotate / flip while placing |
| [ / ] | Brush radius |

---

## 📥 Installation

1. Install **Minecraft Forge 1.12.2**.
2. Put the Forma jar in your `mods` folder.
3. To play on a server, install Forma on the **server** too.

**Permissions:** on servers you need operator rights. In singleplayer, edit in Creative mode.

Schematics are stored in `.minecraft/schematics/`.
